# Logo options

Three candidates are kept here until one is chosen. Each is a geometric SVG with no font dependency, so it renders the same everywhere and stays legible at 24 px on light and dark backgrounds. The README currently uses option B.

| Option | Idea | Image |
| --- | --- | --- |
| A — track | Two rails climbing like a price chart, crossties keeping them in step | <img src="../assets/brand/option-a-track.svg" width="72" alt="Option A"> |
| B — verified ledger | A ledger card with a return line and a check where it reconciles | <img src="../assets/brand/option-b-verified.svg" width="72" alt="Option B"> |
| C — Q-rail | The ring of a Q whose tail runs out as a pair of rails | <img src="../assets/brand/option-c-q.svg" width="72" alt="Option C"> |

Palette: teal `#0F766E` / `#14B8A6`, amber `#F59E0B`, slate `#0F172A`.
